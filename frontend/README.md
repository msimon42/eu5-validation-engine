# Local workbench UI

React + TypeScript + Vite frontend for the local FastAPI service. The backend serves the production `dist/` directory; the repository's Windows launcher handles setup and startup.

For development, start the backend on `127.0.0.1:8765`, then run:

```sh
npm ci
npm run dev
```

The Vite development server binds to loopback and proxies `/api` to that backend. No external fonts or image services are required. Node 22.22.0 was used for the local build and tests; dependency versions are recorded in `package-lock.json`.

```sh
npm run build
npm test
```

The component integration tests use a mocked local API. They verify authenticated command payloads, scan/stage/validation/export ordering, inactive experimental export, explicit design decisions, stale-input rejection, truthful service failures, private source-root registration, and inference policy/key boundaries. These tests do not execute EU5, contact a live model provider, qualify a Windows VM, or establish game conformance.

Transport command kinds are imported from `src/generated/contracts.ts`, generated by the repository's `scripts/generate_contracts.py`. Regenerate that file from the backend contract source instead of editing it manually.
